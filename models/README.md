# 3D models

Each body system is stored at three quality levels so phones download only what they need:

| Suffix | Use |
|---|---|
| `.lite.json` | Low quality, fastest on phones |
| `.full.json` | Balanced (default) |
| `.ultra.json` | Highest detail for strong devices |

Prefixes: no prefix = male body (BodyParts3D), `f-` = female body (Human Reference Atlas), `fx-` = female structures fitted from the male atlas. `skin-`, `hair-` and `photo-` hold the outer body surface.
